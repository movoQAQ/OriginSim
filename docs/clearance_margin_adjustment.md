# 当前起点碰撞余量调整（2026-10-23）

用户要求降低安全余量与栅格误差，机器人半径仍为 0.30 m。运行现场 map 位姿约 (7.271761, 10.137331)，最近静态障碍中心距离 0.35524 m，该格 EDT 为 0.353553 m，旧碰撞阈值 0.385355 m。

bringup 与独立 map_server 默认配置现在使用 safety_margin=0.01、grid_margin_factor=0.4。栅格余量由 resolution×grid_margin_factor 计算，在当前 0.05 m 分辨率下为 0.02 m。硬碰撞阈值为 0.30+0.01+0.02=0.33 m。

Core 保留未配置时的半格对角线默认系数，新参数必须有限且非负。DerivedMap 携带 grid_margin_m，MapClient 校验并传递它，路径连续段检查复用服务端的同一余量。route_monitor.path_blocked.safety_margin 同步为 0.01。MPC 仍保留现有圆形足迹与障碍方格的几何相交检查。

真实 2026 地图回归对比了该坐标：旧配置不可起步，新配置可搜索到附近自由格；无效栅格余量仍被拒绝。测试不表示原有约 0.73 m 的导航/Gazebo 位置差异已经解决。降低余量使机器人更贴近地图障碍，不能补偿定位偏差。

此前 rmuc2026_esdf_tuning.md 的 0.05 m 安全余量、0.38536 m 阈值与统计属于历史记录，当前配置以本文和 YAML 为准。
