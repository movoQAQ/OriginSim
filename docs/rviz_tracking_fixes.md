# 栅格热力图、地图一致性与跟踪修正（2026-10-22）

- 新增 esdf_rviz_plugin/Heatmap，继承 ROS 2 RViz MapDisplay 的纹理栅格绘制，替换连续色表；不是点云。`/map_server/esdf_grid` 是仅供显示的 OccupancyGrid，0–100 映射障碍距离 0–3 m，超过 3 m 饱和。规划仍读取原始浮点距离与代价。当前 Core 距离为无符号障碍距离，不伪造负距离。实现参考 ROS 2 RViz MapDisplay（https://github.com/ros2/rviz/blob/jazzy/rviz_default_plugins/src/rviz_default_plugins/displays/map/map_display.cpp）。
- 活动/原始路径深蓝，平滑路径紫色；Path 使用 transient-local。路径在真实失败或新目标撤销时仍会清空，不保留假的成功路径。
- MapClient 用发布版本水位确认消息，暂存尚未被状态确认的新数组；正常跨 Topic 到达间隔不会撤销可用视图。缺失数组持续超过 map_timeout、错误健康状态、跨生产者拼接仍拒绝运动。暂存仅共享只读缓冲，不复制地图数组。
- 发现启动配置使用 2026 PGM，但实际场景、PCD 均为 2027。已恢复默认 2027，并新增 map 启动参数。切换 2026 时必须同时匹配场景、PCD 和定位变换。

## rmuc2026 隧道研究

原始分辨率 0.05 m。上侧白色狭缝约在像素 x=377..393、下侧 x=188..204，均为 17 个像素，白色宽度约 0.85 m，中心到障碍像素中心最大距离 0.45 m。配置机器人圆半径 0.43 m，安全余量 0.05 m，再计入半个栅格对角线 0.03536 m，硬约束阈值为 0.51536 m，因此两处均被硬碰撞封闭。对应量测见 rmuc2026_tunnels.json。

软代价有限值不会禁止搜索；绿色不是可通行判据。降低 alpha 或 soft_radius 无法解除这两处的硬碰撞。当前未擅自降低机器人外接圆半径。若要求通过，必须核实包含轮组/装甲的实际外形，使用姿态相关足迹和受控过道方向，或修正经实测确认过窄的地图；不能单凭底板 0.50×0.50 m 就忽略外围结构。

## 控制器

1. 横向/纵向误差权重按参考速度的路径切线旋转，独立于固定车体朝向；QP 和非线性验收目标使用相同定义。
2. 最近参考投影限于当前进度向前 1 s，避免邻近回折段跳进度。
3. 按几何曲率约束转弯速度并重新执行前后向加减速限制。
4. 仿真初始延迟补偿从 0.25 s 调为 0.05 s；这是仿真调参值，不是实车延迟标定结果。

## 验证

相关功能包构建通过。地图 44 项回归和控制器 3 项几何/旋转一致性回归通过。
